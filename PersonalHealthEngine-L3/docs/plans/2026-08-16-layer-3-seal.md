# Layer 3 Seal Implementation Plan

> **For Antigravity:** REQUIRED WORKFLOW: Use `.agent/workflows/execute-plan.md` to execute this plan in single-flow mode.

**Goal:** Complete L3A, L3B, and L3C from the sealed read-only Layer 2 database, prove rebuild and incremental equivalence, and seal Layer 3 without implementing Layer 4.

**Architecture:** Preserve the existing normalized-fact model and generic POINT/BUCKET runners. Add an argument-driven Sleep runner, additive migrations for L3B and L3C, deterministic materializers whose outputs retain N:M input provenance, and one authoritative rebuild/audit orchestrator. Incremental processing favors bounded recomputation and semantic correctness over an elaborate invalidation graph.

**Tech Stack:** Python standard library, SQLite, JSON definitions, `unittest`, PowerShell only for orchestration.

**Execution note:** The authorized directory is not a Git repository, so worktree creation and commits are unavailable. Isolation is provided with copied databases under dedicated acceptance directories; production L2 is always opened with SQLite `mode=ro`.
